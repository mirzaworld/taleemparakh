This report is empty. No figures have been published yet.

What this report will show

  • Money in, by source.
  • Money out, by category.
  • The balance carried forward.
  • Any payment to the founder, on its own line, with its purpose.
  • Named supporters only if they chose to be named. Gifts below a set size are shown as a total and a count. A count of fewer than 10 is never shown.

When it will be updated

We plan to publish the first report before any gift is accepted, and then every month.

What the numbers will not show

  • Any student, case or result.
  • Any influence over a finding. Money never changes a result.
