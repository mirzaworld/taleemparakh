تعلیم پرکھ کو ہوم اسکرین پر محفوظ کریں

آپ تعلیم پرکھ کو اپنے فون یا لیپ ٹاپ پر اس طرح رکھ سکتے ہیں کہ وہ ایپ کی طرح کھلے۔ یہ مفت ہے۔ اس کے لیے ایپ اسٹور نہیں چاہیے، اور یہ آپ کو ٹریک نہیں کرتا۔ تعلیم پرکھ کو صحیح براؤزر میں کھولیں، پھر براؤزر کے اپنے مینو سے اسے شامل کریں۔ آئی فون، اینڈرائیڈ اور لیپ ٹاپ کے مراحل نیچے ہیں۔

شروع کرنے سے پہلے

صحیح براؤزر استعمال کریں۔ آئی فون یا آئی پیڈ پر سفاری، اینڈرائیڈ فون پر کروم، اور لیپ ٹاپ پر کروم یا ایج۔

پہلے ایڈریس چیک کریں۔ اصل تعلیم پرکھ کا ایڈریس نیچے ڈبے میں دیا گیا ہے۔ ویب سائٹوں کی نقلیں موجود ہوتی ہیں اور نقل بالکل اصل جیسی لگ سکتی ہے۔ ایڈریس خود ٹائپ کریں یا کسی قابلِ اعتماد شخص کا بھیجا ہوا لنک استعمال کریں، اور کسی غیر متوقع پیغام میں آنے والا لنک استعمال نہ کریں۔

سرکاری ایڈریس

taleemparakh.org

آئی فون اور آئی پیڈ (سفاری)

پرانے فون پر بٹنوں کے نام کچھ مختلف ہو سکتے ہیں۔ اگر کوئی مرحلہ نہ ملے تو کسی قابلِ اعتماد شخص سے مدد لیں۔

  1. تعلیم پرکھ کو سفاری میں کھولیں۔
  2. شیئر کا بٹن دبائیں۔ یہ ایک چوکور ہے جس میں اوپر کی طرف تیر بنا ہوتا ہے۔
  3. نیچے سکرول کریں اور Add to Home Screen دبائیں۔
  4. Open as Web App کو آن رہنے دیں۔ ایپل کا نیا سافٹ ویئر (آئی او ایس 26 اور بعد کے ورژن) ہوم اسکرین میں شامل کی گئی ویب سائٹ کو خود بخود ویب ایپ کی طرح کھولتا ہے۔
  5. Add دبائیں۔ اب تعلیم پرکھ کا آئیکن آپ کی ہوم اسکرین پر ہے۔

اینڈرائیڈ فون (کروم)

اگر Install app نظر نہ آئے تو سائٹ کو تھوڑی دیر استعمال کریں اور پھر مینو دوبارہ کھولیں۔

  1. تعلیم پرکھ کو کروم میں کھولیں۔
  2. اوپر دائیں طرف تین نقطوں والا مینو بٹن دبائیں۔
  3. Install app دبائیں۔ اگر اس کی جگہ Add to home screen نظر آئے تو وہ دبائیں۔
  4. Install یا Add دبائیں اور تصدیق کریں۔
  5. تعلیم پرکھ کا آئیکن اپنی ہوم اسکرین یا ایپس میں تلاش کریں۔

لیپ ٹاپ (کروم یا ایج)

ایج اپنے مینو میں عموماً یہی سہولت دیتا ہے۔

  1. تعلیم پرکھ کو کروم یا ایج میں کھولیں۔
  2. ایڈریس بار کے دائیں سرے پر انسٹال کا آئیکن دیکھیں اور اسے دبائیں۔ کروم میں آپ مینو کھول کر Cast, save, and share اور پھر Install page as app بھی چن سکتے ہیں۔
  3. اسکرین کی ہدایات پر عمل کریں۔ اب تعلیم پرکھ اپنی الگ ونڈو میں کھلتا ہے۔

انٹرنیٹ کے بغیر کیا چلتا ہے

چیکس، رہنما مضامین اور آخری کھولی ہوئی خبریں انٹرنیٹ کے بغیر چلتی ہیں۔ رجسٹر کی فہرستیں وہ آخری کاپی ہیں جو آپ کے فون نے محفوظ کی، اور ایپ بتاتی ہے کہ وہ پرانی ہو سکتی ہیں۔

درخواست بھیجنے یا اس کی پیروی کے لیے انٹرنیٹ چاہیے۔ ہم آپ کی درخواست بعد میں بھیجنے کے لیے محفوظ نہیں کرتے، اس لیے کچھ دو بار نہیں جاتا۔

دوبارہ سائن اِن کرنا

ہر بار کھولنے پر آپ کو دوبارہ سائن اِن کرنا پڑ سکتا ہے۔ یہ جان بوجھ کر ہے۔ اگر کوئی اور آپ کا فون استعمال کرے تو اس سے آپ کی درخواستیں نجی رہتی ہیں۔

اپ ڈیٹ کیسے آتی ہے

جب نیا ورژن ہو تو ایک پٹی بتاتی ہے کہ نیا ورژن تیار ہے۔ Update now دبائیں۔ ایپ اسٹور کی ضرورت نہیں۔ آپ کی درخواستیں آپ کے اکاؤنٹ میں رہتی ہیں، فون میں نہیں۔

اسے ہٹانے کا طریقہ

فون پر تعلیم پرکھ کے آئیکن کو دبائے رکھیں جب تک مینو نہ کھلے، پھر اسے ہٹانے یا ڈیلیٹ کرنے کا انتخاب چنیں۔ اس سے صرف شارٹ کٹ ہٹتا ہے۔

لیپ ٹاپ پر کروم میں ایپ کھولیں، اوپر دائیں طرف مینو کھولیں اور Uninstall TaleemParakh چنیں۔

محفوظ رہیں

تعلیم پرکھ کو محفوظ کرنے سے کوئی ایسی چیز انسٹال نہیں ہوتی جو آپ کو ٹریک کرے۔ یہ وہی ویب سائٹ ہے جو شارٹ کٹ کے طور پر رکھی گئی ہے۔ اس میں اشتہار اور ٹریکر نہیں ہیں۔

ہم آپ سے کبھی کوئی اور ایپ انسٹال کرنے کو نہیں کہتے، اور ہم واٹس ایپ یا ٹیکسٹ میسج پر ایپ انسٹال کرنے کے لنک نہیں بھیجتے۔ اگر کوئی پیغام کہے کہ وہ تعلیم پرکھ کی طرف سے ہے اور کچھ انسٹال کرنے کو کہے تو وہ ہماری طرف سے نہیں۔ اسے نہ دبائیں۔

اگر کچھ ٹھیک نہ لگے

رک جائیں، کوئی تفصیل درج نہ کریں، اور والدین یا کسی قابلِ اعتماد شخص کو بتائیں۔ مدد کے نمبر اس صفحے کے آخر میں ہیں۔

عام سوالات

کیا اس پر پیسے لگتے ہیں؟

نہیں۔ تعلیم پرکھ مفت ہے، اور اسے ہوم اسکرین پر محفوظ کرنا بھی مفت ہے۔

کیا یہ ایپ اسٹور استعمال کرتا ہے؟

نہیں۔ آپ اسے اپنے براؤزر سے شامل کرتے ہیں۔ آپ کو ایپ اسٹور اکاؤنٹ کی ضرورت نہیں۔

کیا یہ مجھے ٹریک کرتا ہے؟

نہیں۔ اسے محفوظ کرنے سے کوئی ٹریک کرنے والی چیز انسٹال نہیں ہوتی، اور تعلیم پرکھ میں اشتہار یا ٹریکر نہیں ہیں۔

ابھی مدد چاہیے؟

تعلیم پرکھ کے پاس انسانی جائزہ کار ابھی نہیں ہیں، اور کوئی ہنگامی سروس نہیں ہے۔ یہ عوامی سروسز ہیں جن سے آپ خود رابطہ کر سکتے ہیں۔ براہِ کرم آج ہی کسی قابلِ اعتماد شخص سے بھی بات کریں۔
